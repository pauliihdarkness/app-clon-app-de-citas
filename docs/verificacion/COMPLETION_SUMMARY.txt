💻 PARA DESARROLLADORES:

Acceder a lista de bloqueados:
──────────────────────────────
const [blockedContacts, setBlockedContacts] = useState([]);
useEffect(() => {
  const stored = localStorage.getItem('blockedContacts');
  if (stored) setBlockedContacts(JSON.parse(stored));
}, []);


Desbloquear un contacto:
───────────────────────
const unblockContact = (contactId) => {
  setBlockedContacts(prev => 
    prev.filter(contact => contact.id !== contactId)
  );
};


Guardar bloqueos:
────────────────
localStorage.setItem('blockedContacts', JSON.stringify(blockedContacts));


Mostrar badge en perfil:
───────────────────────
import VerificationBadge from './components/UI/VerificationBadge';
<VerificationBadge size="medium" />


Verificar estado:
────────────────
import { useVerification } from './context/VerificationContext';
const { isVerified } = useVerification();


Redirigir a verificación:
────────────────────────
navigate('/verify-identity');
